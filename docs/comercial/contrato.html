Qué es un cambio chico

Sí: cambiar textos, precios, horarios, fotos o datos de contacto; sumar o sacar un producto, un servicio o una novedad de una lista que ya existe. Son pedidos de hasta una hora de trabajo.

No: una función o una pantalla nueva, rehacer el diseño, conectar otro sistema o mudar el sitio de lugar. Eso se cotiza aparte —[monto] la hora— y siempre se avisa el precio antes de empezar.

Los pedidos entran por correo a hola@kalabs.dev y se hacen juntos una vez por semana; si el sitio se cae o algo deja de funcionar, se atiende el mismo día. Los cambios que no se usan en el mes no se acumulan para el siguiente. El plan se paga mes a mes y se corta avisando con 30 días.
